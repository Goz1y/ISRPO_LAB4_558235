# geometric_lib

Python-библиотека для вычисления площади и периметра геометрических фигур: круга, квадрата и треугольника.


## Возможности

- `circle.py` — площадь круга и длина окружности;
- `square.py` — площадь и периметр квадрата;
- `triangle.py` — площадь треугольника по основанию и высоте, а также периметр по трём сторонам;
- покрытие всех функций unit-тестами на `unittest`.

## Структура проекта

```text
geometric_lib/

├── square.py           # площадь и периметр квадрата

├── test_circle.py      # unit-тесты для circle.py
├── test_square.py      # unit-тесты для square.py
├── test_triangle.py    # unit-тесты для triangle.py
